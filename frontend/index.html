About CheckUp
Workplace mental health detection from voice
Project overview

CheckUp is an end-to-end machine learning pipeline that analyses voice recordings to detect workplace mental health states — calm, stressed, or distressed — using deep learning on audio features.

Built as an extension of prior mental health prediction research, this project moves from tabular survey data to real audio signals, making the detection more immediate and applicable in workplace settings.

Python TensorFlow FastAPI Librosa Docker
How it works

Each audio file is converted into a 40×174 MFCC (Mel Frequency Cepstral Coefficient) matrix — a 2D fingerprint of the voice's frequency patterns over time. A 3-block CNN then classifies these patterns into one of 3 workplace states.

Dataset — CREMA-D

The CREMA-D dataset contains 7,442 audio files from 91 actors expressing 6 emotions. After data augmentation (noise, pitch shift, time stretch), the training set grew to 29,768 samples.

Model architecture

3-block CNN with BatchNormalization and Dropout regularization. Trained for 80 epochs with EarlyStopping and ReduceLROnPlateau callbacks.
